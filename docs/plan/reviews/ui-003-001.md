# Review: ui-003

## Findings

- **P1 · resolved** — A review could not be looked at again: the artifact was written and never read. `GET /api/reviews` lists the stored reviews and `GET /api/reviews/:id` returns one. The stored body and the live body come from the same `reviewResponseBody()`, so a reopened review renders identically to the run that produced it.
- **P1 · resolved** — A stored review id was not constrained. `readReviewArtifact()` accepts only `^[A-Za-z0-9_-]{1,128}$` and resolves the path under the review directory, so `..%2F..%2Fetc%2Fpasswd` is a 404 and not a file read.
- **P1 · resolved** — A model configuration could not be tested without saving it. `POST /api/settings/models/test` resolves the profile and sends one short prompt, and reports the round trip. It never writes: the test resolves against a throwaway catalog, so a test's Base URL cannot overwrite the saved profile. A test asserts the stored profile is byte-identical afterwards.
- **P2 · resolved** — The ledger could not be narrowed down. Severity and document filters were added next to the status tabs, and the search now covers the rationale and the quoted wording, not only the title. The header reports the match count whenever the visible set is smaller than its group.
- **P1 · resolved** — The search field was destroyed on every keystroke, because the whole ledger was re-rendered on each input event. The toolbar is now rendered once per mount and filtering repaints only the entry list and the match count, so the field keeps focus and no character is lost.
- **P2 · resolved** — The Library could not start a review. `POST /api/review/from-library` reads the archived source files, so a review no longer needs the same files uploaded again. It writes the same stream and therefore the same artifact format as `POST /api/review`.
- **P2 · accepted** — Two documents could only be compared through a single finding. The `文档对照` panel shows two documents' archived Markdown side by side. It reuses `documents[].markdown` from the review response, so it added no endpoint of its own.
- **P2 · accepted** — The Library has one row per archived document, so repeated reviews of the same three contracts have piled up thirty-three rows. They are distinct documents with distinct ids; de-duplicating them is a decision about document identity rather than a rendering fix.
- **P2 · accepted** — The connection test proves reachability, not image capability. The vision panel says so in the result tooltip instead of implying more than was checked.
